# TaleemOne — Staff Application

Institutional Mobile Application for Teachers, Clerks, Accountants, and Academic Staff built for the TaleemOne ERP ecosystem.

---

## 🏛️ Architecture & Tech Stack

- **Framework**: Flutter (Dart)
- **Architecture**: Flutter Clean Architecture (`Presentation` ➔ `Domain` ➔ `Data`)
- **State Management**: `flutter_bloc`
- **Branding**: Universal Liquid Crystal Glassmorphism
- **Signature**: Powered by Barkat Tech

---

## 📂 Project Structure

- [`staff-app/`](staff-app/): Complete Flutter mobile application source code.
  - `lib/`: Domain entities, repositories, use cases, BLoCs, and presentation UI.
  - `android/`: Android platform configuration.
  - `ios/`: iOS platform configuration.
  - `assets/`: Static images, icons, and fonts.
  - `test/`: Unit and widget tests.

---

## 🚀 Getting Started

1. Navigate to the app directory:
   ```bash
   cd staff-app
   ```
2. Get Flutter dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
